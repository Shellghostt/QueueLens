# Collector protocol

The wire contract between an adapter (or an SDK) and the collector is versioned (`v1`) and defined in
docs/PLAN.md section 9. Adapters in other languages implement this protocol; they do not import Go
packages.

The Go implementation lives in `pkg/protocol` and has no dependencies on the rest of QueueLens.

## Event schema v1

```json
{
  "v": 1,
  "id": "01J8Z8Q9K3",
  "ts": "2026-11-13T10:00:00.123Z",
  "queue": "email",
  "job_id": "8891",
  "job_name": "send-welcome",
  "attempt": 2,
  "state": "failed",
  "worker_id": "w-7",
  "duration_ms": 340,
  "error": "SMTP timeout"
}
```

| Field | Required | Rules |
|---|---|---|
| `v` | yes | Must be `1`. Any other value rejects the event. |
| `ts` | yes | RFC 3339. More than 7 days old is rejected and counted separately. More than 1 hour in the future is rejected as clock skew. |
| `queue` | yes | At most 256 characters. |
| `job_id` | yes | At most 256 characters. |
| `id` | no | Generated by the collector when it is omitted. ULID, sortable by time. |
| `job_name` | no | At most 256 characters. |
| `attempt` | no | Defaults to 1. Must not be negative. |
| `state` | yes | One of `enqueued`, `started`, `completed`, `failed`, `retried`, `stalled`, `drained`. |
| `worker_id` | no | At most 128 characters. |
| `duration_ms` | no | Must not be negative. |
| `error` | no | Truncated to 1,024 bytes and redacted on a best-effort basis. |

Unknown fields are ignored on purpose, so a newer adapter does not break an older collector.

## Transport

```
POST /v1/events
Authorization: Bearer <token>
Content-Type: application/json
```

The body is a single event object or an array of up to 1,000 events, at most 1 MiB in total.

```json
{
  "accepted": 998,
  "dropped": 0,
  "rejected": [
    {"index": 4, "id": "", "reason": "job_id: is required"}
  ]
}
```

- `202`: the batch was accepted. Some events may still have been rejected individually.
- `400`: the body could not be read, or every event in the batch was rejected.
- `429`: the collector's buffer was full. The events that did not fit were dropped and counted.
  The response carries `Retry-After: 1`.

A producer must treat 202 and 429 as non-fatal and must not retry synchronously from the job path.

## Conformance

The Go implementation of this contract is `pkg/protocol`. The M2 milestone adds a shared conformance
test that every SDK, in every language, has to pass.
